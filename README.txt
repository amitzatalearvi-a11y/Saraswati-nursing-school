PREVIEW
Open index.html in a web browser. Keep the assets folder, styles.css and script.js together with index.html.

FREE PUBLISHING WITH GITHUB PAGES
1. Sign in to GitHub and create a new public repository (for example: saraswati-nursing-school).
2. Extract this ZIP on your device.
3. Upload the CONTENTS of the saraswati_nursing_school_website folder to the repository root (index.html must be at the root).
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
6. GitHub will show the public Pages website address in Settings > Pages after deployment.
